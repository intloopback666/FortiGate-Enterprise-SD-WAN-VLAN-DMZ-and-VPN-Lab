*********************************************************
Recommended operational controls:

- Change the default administrator password.
- Create named administrator accounts.
- Disable HTTP administrative access.
- Limit HTTPS and SSH administration to the management network.
- Configure trusted hosts for all admin accounts.
- Enable NTP.
- Send logs to FortiAnalyzer, syslog, or FortiCloud.
- Enable configuration backups.
- Use MFA for SSL-VPN.
- Do not allow WAN administrative access.
- Keep FortiOS updated to a supported release.
- Enable logging on all allow and deny policies.
- Use least privilege between VLANs.
- Do not permit DMZ-initiated access to internal networks.
- Use a separate management VLAN and preferably a dedicated out-of-band management network.
